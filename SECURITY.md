# Security Policy / セキュリティポリシー

脆弱性を見つけた場合は、公開の Issue ではなく、GitHub の **Security Advisories**
（リポジトリの「Security」タブ → 「Report a vulnerability」）から非公開で報告してください。

If you find a vulnerability, please report it privately through GitHub **Security Advisories**
(repository → Security → Report a vulnerability) rather than a public issue.

特に次の点の指摘を歓迎します / Reports about these are especially welcome:

- 乱数の偏りや予測可能性 / bias or predictability in the generated values
- 生成結果が外部へ送られうる経路 / any path by which results could leave the device
- CSP や Service Worker の抜け穴 / gaps in the CSP or Service Worker
